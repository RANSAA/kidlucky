### 功能说明：

该仓库主要用来存放一些静态的配置数据。

注意：

1. 存放的数据不能违规，比如不能存放黄色的视频，图片，文字。
2. 用户名称与该仓库的名称不能随便更改，因为更改后文件的访问链接也会更改。
3. 该仓库必须是一个公开的仓库，否则无访问权限。

### 目前存放的数据:

文件名称：**cts-v3**

功能简介：iOS APP管理控制程序的服务源加密文件，加密规则请查看《[TKAppManager-APP](https://github.com/RANSAA/TKAppManager-APP)》
